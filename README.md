# Zonix

**Zonix** is a learning project focused on building a modern e-commerce backend from scratch using Python and Django.

The project is developed step by step, documenting the development process, technical decisions, challenges, and solutions.

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Redis
- RabbitMQ
- Docker

## Planned Features

- User registration and authentication
- Product catalog and categories
- Product search and filtering
- Shopping cart
- Order management
- Role-based permissions
- Background task processing
- Caching
- Automated testing

## Development Approach

This project is built incrementally.

Each stage introduces new concepts and technologies, with practical implementation and documentation.

The goal is to understand backend development, software architecture, and the interaction between different technologies.
